# GitHub Pages Notes

## Why GitHub Pages?
- Free hosting for static websites.
- No Replit Agent.
- No API credits.
- No monthly hosting cost.

## Good fit for this project
- HTML, CSS, and JavaScript only.
- Runs entirely in the browser.
- Uses localStorage for saves.
- No backend server required.

## Publish steps
1. Upload `index.html`, `style.css`, and `script.js`.
2. Go to Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: main.
5. Folder: /(root).
6. Save.
7. Wait a minute or two for deployment.

Expected URL:
`https://whaledoescode.github.io/clicker_game.v1/`

## Notes
- Browser save key: `clickerGameSaveV1`.
- Saves stay on the same browser/device unless browser data is cleared.
